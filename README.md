Leonida Legend — an offline guide and tracker for all 55 GTA 6 trophies on PlayStation 5: a saved checklist with export/import, filters and a spoiler setting, a 5-stage roadmap to the platinum, the one missable trophy flagged, and a cited guide (steps + named sources) for every trophy.

## Run it

```sh
python3 -m http.server 8080 --directory app
# open http://localhost:8080 in a desktop browser (works with the network off)
```
